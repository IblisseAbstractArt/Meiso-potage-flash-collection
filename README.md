this is a collection of adobe flash (games and animations)
From Meiso potage (alias Mesopota) and this repository is dedicated
ONLY to touhou flash files.

Why? because this project is meant to revive those old-outdated
flash content.

this project was born by one day i was bored... and when i took a look
to the mesopota archives, i've got interested in the files some
folders contain... so i thought "why not bring those back functional using ruffle?"
and thats how this small proyect was born.

the goal of the project is to make those old flash contents return to life
working back using ruffle in my own website i did, inspirated in the site of mesopota.net. the proyect started in a local private server, but I've wanted to share it with the world with flash content from Meisou Potage that you cant find in any other place besides this site...
